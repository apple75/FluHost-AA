# Project overview

FluHost-AA is a computational bioinformatics and reproducibility project for publicly available, naturally occurring Influenza A sequences. Its current analytical focus is HA host-associated amino-acid statistical signals. The longer program adds subtype-aware validation, phylogenetic and reassortment context, and ML generalization. It is computational research, with no virus design or engineering work.

The repository currently provides governance and a directory structure. The [project scope contract](../contracts/project/scope_v1.0.yaml) is frozen; the [F0 legacy baseline contract](../contracts/science/f0_legacy_baseline_v1.0.yaml) is draft and retains unresolved historical choices. No validated results are presented. See the [roadmap](../ROADMAP.md) for intended phases and the [README](../README.md) for the repository map.
