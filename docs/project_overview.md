# Project overview

FluHost-AA studies host-associated amino-acid statistical signals in publicly available, naturally occurring Influenza A sequences. The current focus is HA Human vs Avian analysis. The broader program includes subtype-aware robustness, phylogenetic and reassortment context, and ML generalization. The work is computational and observational; it does not design or engineer viruses.

The project reports Kaggle runtime validation of HA dataset reconstruction, subtype-specific MSA, reference-position mapping, all-subtype Human vs Avian frequencies, and within-subtype frequency differences. **This GitHub repository does not yet contain the corresponding code, run records, QC summaries, output manifests, or results for independent verification.** HA site prioritization, H1/H3 detailed work, statistical testing, and cross-subtype consistency are in progress. Temporal, geographic, lineage, and phylogeny-aware validation, reassortment context, and ML benchmarks are planned. These statuses do not claim scientific validation or causal effects.
