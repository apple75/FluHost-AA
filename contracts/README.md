# FluHost-AA Contracts

This directory contains governed project and scientific contracts.

Contracts define research rules that must not be changed silently by
implementation agents.

Scientific contracts may govern:

- host ontology
- inclusion/exclusion rules
- QC thresholds
- references
- numbering systems
- statistical tests
- multiple-testing correction
- sampling rules
- lineage definitions
- temporal splits
- benchmark splits

Runtime configuration belongs in `configs/`, not in scientific contracts.

Contract changes follow:

Proposal -> PI Review -> Contract Update -> Implementation
